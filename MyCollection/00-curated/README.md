# Curated DBA Triage

Use these folders first during incidents. They contain a small, high-signal set of read-only starter scripts and runbooks.

- `performance`: slow SQL, waits, top resource queries, IO latency.
- `blocking`: blockers, blocked sessions, open transactions.
- `indexes`: missing index and unused index signals.
- `backups`: backup health and restore readiness checks.
- `security`: privileged access and login checks.
- `configuration`: server and database configuration checks.
- `troubleshooting`: cross-topic workflows.

If these files are insufficient, search the broader `MyCollection` folders, then the upstream repo folders.
