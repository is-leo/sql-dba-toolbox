# Cases

Use this folder for sanitized troubleshooting notes and result summaries.

Do not store customer names, server names, IP addresses, usernames, passwords, private keys, proprietary query text, or screenshots that expose sensitive data.

Use `templates/slow-sql-case-template.md` for the first milestone workflow.

Use `templates/DBA_Troubleshooting_Intake_Form.docx` when you need a human-facing intake form for symptoms, suspected root cause, business impact, and recommended diagnostic tools.
