## ppt/slides/slide33.xml
33
Uncomplicate Data Storage, Forever
About the Scripts & Automation
This technique has been used to migrate 1000’s of instances since 2009
At the peak these scripts moved 3 servers a week for about 3 years.
Each server contained 100+ databases
Downtime was minimal (just a few minutes)
Easy Rollback
Every time a bug was found steps were added to the process
This technique migrates one instance to another
It does not move individual databases but entire instances
It accounts for everything I encountered except for an IP address
It even accounts for moving replication between servers and not having to reinitialize any replication
This is broken down into several stages
