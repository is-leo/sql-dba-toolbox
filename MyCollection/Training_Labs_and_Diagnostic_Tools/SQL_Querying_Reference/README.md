# SQL Querying Reference

This folder contains compact SQL querying reference material.

Files:

- `Joins_Cheat_Sheet_Ledger.pdf`: visual/reference material for SQL joins.

## Use

Use this folder for quick reminders about join types and query-shape reasoning. This is learning/reference material rather than incident tooling.

For performance incidents involving joins, use this only for interpretation. Diagnose with execution plans, row estimates versus actuals, indexing, predicates, statistics, and wait/query evidence from `MyCollection/00-curated`.
