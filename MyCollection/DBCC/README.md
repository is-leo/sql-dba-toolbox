# DBCC Scripts

Use this folder for DBCC-related working scripts and examples.

Review each script before running it. DBCC commands range from safe read-only checks to commands that alter cache state, shrink files, change trace flags, or expose undocumented internals.

For structured course material and lab exercises, use `MyCollection/Training_Labs_and_Diagnostic_Tools/DBCC_Commands_Training`.

For corruption-specific learning and repair/restore tradeoffs, use `MyCollection/Training_Labs_and_Diagnostic_Tools/Database_Corruption_Training`.
