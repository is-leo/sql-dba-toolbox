# Availability Groups Operational Scripts

Use this folder for operational SQL Server Availability Groups checks and supporting scripts.

Start here for read-only AG troubleshooting and status review, including AG health, replica/database status, listener information, preferred backup node checks, readable secondary checks, failover timing, and whether a database is primary or secondary.

For AG build/configuration training material, checklists, endpoint creation, certificate setup, listener setup, routing, and other change-oriented examples, use `MyCollection/Training_Labs_and_Diagnostic_Tools/Availability_Groups_Administration_Training` instead.

Do not run change-oriented scripts such as login/job synchronization setup, linked server creation, failover, or backup routing changes without an approved change plan, risk notes, rollback steps, and validation.
