# MyCollection

Personal SQL Server DBA knowledge base and script library.

Start here: `USAGE.md`.

Use this structure:

- `00-curated`: first-stop troubleshooting scripts and runbooks.
- `10-cases`: sanitized case notes and templates.
- Other folders: broader local script source material by topic or author.

The repository root remains mostly aligned with the upstream `ktaranov/sqlserver-kit` project. Use `AGENTS.md` for Copilot troubleshooting behavior.
